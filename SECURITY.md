# Security / 安全问题

For vulnerabilities involving private data or file loss, contact the maintainer of this repository through a private channel. If this repository has private vulnerability reporting enabled, use Security → Report a vulnerability. Include the affected version, reproduction steps, and expected impact. Share sanitized diagnostics and sample data.

涉及隐私数据或文件丢失的漏洞，请通过私有渠道联系当前仓库维护者。如果仓库启用了私有漏洞报告，可在 Security → Report a vulnerability 中提交。请附受影响版本、复现步骤和影响说明，并对诊断资料及示例数据脱敏。

The upstream project's security contacts apply to its own releases. This repository's maintainer will publish contact details after repository creation.

上游项目的安全联系方式适用于上游发布物，当前仓库维护者将在仓库建立后补充联系方式。
